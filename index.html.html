Cài đặt

Chạy được trong 5 phút

1
Tải và giải nén

Tải file ZIP về máy tính, giải nén vào thư mục bất kỳ.

2
Cài Node.js

Tải Node.js tại nodejs.org nếu chưa có. Sau đó mở CMD trong thư mục vừa giải nén và chạy:

npm install
3
Khởi động

Chạy file START TV.bat — server tự khởi động và mở trình duyệt. Kéo cửa sổ sang TV là xong!

4
Kết nối điện thoại

Dùng điện thoại quét mã QR trên TV. Màn hình remote mở ngay — không cần cài app gì thêm.
